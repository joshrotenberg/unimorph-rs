# Commands

This section provides detailed documentation for each unimorph command.

## Data Management

- [download](./download.md) - Download language datasets from UniMorph
- [list](./list.md) - List available and cached languages
- [update](./update.md) - Update cached datasets to latest versions
- [delete](./delete.md) - Remove cached datasets
- [repair](./repair.md) - Repair or reset the data store
- [export](./export.md) - Export datasets to files

## Querying

- [inflect](./inflect.md) - Look up all inflected forms of a lemma
- [analyze](./analyze.md) - Analyze a surface form (reverse lookup)
- [search](./search.md) - Search with flexible filtering
- [features](./features.md) - Explore morphological features

## Information

- [stats](./stats.md) - Show dataset statistics
- [info](./info.md) - Show detailed language info

## Configuration

- [config](./config.md) - Manage configuration settings
